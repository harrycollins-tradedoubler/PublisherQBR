# Publisher QBR Frontend

This Vite/React app is retained as a legacy app-hub interface for Publisher QBR compatibility work.

It is not required for the active local runtime, which is:

```text
Chrome extension -> local Publisher QBR runner -> qbr-pptx-service
```

Use the Chrome extension in `publisher-qbr-chrome-extension-prototype/` for active local Publisher QBR generation.

## Development

```powershell
cd frontend
npm install
npm run dev
```

Default URL:

```text
http://localhost:5173
```

## Checks

```powershell
cd frontend
npm run build
```
